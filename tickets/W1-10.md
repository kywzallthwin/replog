# W1-10: Add Browser Coverage And Complete The Wave 1 Gate

**State:** proposed

## Goal
Automate the critical mobile journey and confirm the Wave 1 acceptance gate.

## Scope
- Add or complete local Playwright coverage at 375px for public auth, navigation, program selection, workout completion, and history.
- Run final checks and record remaining manual evidence from the current router and tickets.

## Out of scope
- New mockup features, production deployment, staging, load, security, or account-lifecycle work.

## Acceptance criteria
- Critical browser flows run repeatably against the local application.
- The browser project uses a 375px viewport and produces useful failure artifacts.
- Client/server tests, lint, typecheck, build, and diff checks pass.
- Manual 375px findings are closed or have approved follow-up tickets.
- `STATUS.md` records Wave 1 completion or the precise blocker; Phase 4 remains blocked if incomplete.

## Verification
- Run `npm run check` and the Playwright suite against local services.
- Manually verify critical flows at 375px, then spot-check 768px and 1080px.
- Review the complete Wave 1 diff.

## Stop conditions
- Stop if a failure requires new scope, an unresolved decision, or unsafe local data use.

# W2-13: Editable Exercise Categories

State: done

## Goal
Replace the fixed exercise-category enum with immutable built-ins and private user-managed categories.

## Scope
- Add the category model, migration, authenticated category APIs, and category-aware exercise contracts.
- Update program/progress payloads and the exercise picker to use category summaries.
- Preserve exercise, program, and session references during migration.

## Out of scope
- Production migration or deployment.
- Exercise renaming and archival deletion from W2-06.
- Resuming W2-03 until this ticket is complete.

## Verification
- Focused server/client tests, Prisma validation, migration tests, `npm run check`, and independent migration/API review.
- Acceptance covered API-backed detailed categories and ID-based creation, category CRUD and duplicate protection, built-in/global read-only behavior, owner-only recategorization, and transactional deletion reassignment.
- Migration mappings preserve exercise IDs and existing program/session references. The migration was not applied to production.

## Risks and rollback
- Validate the enum-to-category migration on a backup or isolated database before deployment.
- Rollback requires restoring the pre-W2-13 backup and deploying the previous application version; do not manually drop category tables.

## Stop conditions
- Do not apply the migration to production; require backup and explicit authorization.

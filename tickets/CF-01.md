# CF-01: Cloudflare Edge Proxy and Static Assets

**State:** proposed  
**Implementer:** Edge agent  
**Reviewer:** Security review agent

## Goal

Create an isolated Cloudflare Worker that serves React and safely implements the [CF-00](CF-00.md) proxy contract.

## Scope

- Add an `edge` npm workspace with Worker source, Wrangler config, TypeScript/ESLint, Vitest, and preview/package/upload/deploy scripts.
- Add root workspace dependencies/scripts and Cloudflare static security/cache headers.

## Owned Files

`edge/**`, root `package.json`, `package-lock.json`, `.gitignore`, and `client/public/_headers`. Do not edit client runtime, Express, `STATUS.md`, or other tickets.

## Implementation

- Configure `assets.directory: "../client/dist"`, `not_found_handling: "single-page-application"`, and `run_worker_first: ["/api", "/api/*", "/ready"]`.
- Validate `API_UPSTREAM_ORIGIN` as a credential-free HTTPS origin without path/query/fragment.
- Build upstream URLs only from that origin and allowed incoming path/query; reject encoded boundary escapes.
- Stream methods/bodies and preserve query, `Origin`, cookies, content headers, response status/body, redirects, and all `Set-Cookie` values.
- Apply CF-00 header stripping, inject the shared edge secret/request ID, and use manual redirects.
- Apply 12-second readiness and 30-second API timeouts.
- Reject HTML on proxy routes and strictly require readiness `{ "ok": true }`.
- Permit proxying only for exact `PUBLIC_APP_ORIGINS`; preview origins receive controlled `503` responses.
- Never cache proxy responses. Revalidate the SPA shell and cache fingerprinted assets as immutable.

## Environment

| Variable | Secret | Purpose |
|---|---:|---|
| `API_UPSTREAM_ORIGIN` | No, runtime-only | Exact Render HTTPS origin |
| `PUBLIC_APP_ORIGINS` | No | Exact production/validation origins |
| `EDGE_PROXY_SECRET` | Yes | Authenticates the RepLog Worker to Render |
| `VITE_API_URL` | Must be unset | Same-origin browser API |

## Verification

```text
npm run test -w edge
npm run lint -w edge
npm run typecheck -w edge
npm run build -w client
npm run package -w edge
```

Test routes and encoded boundaries, URL/query construction, methods/streaming, header stripping, spoofing, redirects, multiple cookies, errors/timeouts, HTML/readiness validation, caching, asset/SPA bypass, and preview rejection.

## Acceptance Criteria

- Unknown paths cannot reach Render.
- SPA deep links and static assets resolve correctly.
- Render HTML cannot become an API success.
- Multiple cookies remain separate.
- Proxy responses are never cached.
- Previews cannot access production API/data.

## Stop Conditions

Stop if cookies cannot be preserved, an unrestricted proxy is required, secrets would enter `VITE_*`, or proxy/SPA routes cannot be reliably separated.

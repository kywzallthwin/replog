# CF-04: Cross-Stack Authentication and Integration

**State:** review
**Implementer:** Integration agent
**Reviewer:** Security review agent
**Verifier:** Coordinator agent

## Goal

Prove Cloudflare, React, Express, cookies, OAuth, password reset, and cold-start recovery work together before production cutover.

## Scope

- Add local Worker-to-Express integration coverage.
- Add/extend browser tests for startup, auth, cookies, stale tabs, caching, and mutations.
- Document architecture, environment, preview, deployment, and rollback.
- Run complete repository verification.

## Owned Files

Integration/E2E tests, test runner configuration and bounded scripts, README, and environment/deployment documentation. Do not change CF-01–CF-03 core implementation; return findings to the owning implementer.

## Scenarios

- Cloudflare serves React against healthy Render and against startup HTML followed by readiness success.
- Registration/login use same-origin `/api`; the auth cookie belongs to Cloudflare.
- Authenticated refresh works and logout clears matching attributes.
- Invalid credentials remain `401`; multiple `Set-Cookie` values survive.
- Google initiation preserves external redirect; callback passes through Cloudflare and returns to `CLIENT_URL`.
- OAuth state cookie has the Cloudflare host and `/api/auth/google` path.
- Password-reset links use the Cloudflare origin.
- Stale authenticated `GET` wakes and replays once; stale login checks readiness first.
- A representative mutation is sent exactly once.
- Direct Render API fails after enforcement while direct `/health` works.
- API/auth/health/readiness responses are not cached.
- SPA routes/assets never contain Render startup HTML.

## Acceptance Criteria

- Full verification passes.
- Cookies are first-party to Cloudflare.
- OAuth/reset URLs use Cloudflare.
- API cannot fall through to the SPA and SPA routes cannot reach Render.
- Recovery cannot duplicate mutations.
- Logs correlate requests without sensitive data.

## Stop Conditions

Stop if cookies need `SameSite=None` or `Domain`, OAuth requires direct Render navigation, mutations replay, authenticated responses cache, or testing requires unauthorized production access.

# W2-04: Active-Workout Exercise Reordering

State: done

## Goal
Let an owner change exercise order inside an active workout without altering the source program or completed history.

## Scope
- Add an authenticated active-session exercise reorder endpoint with validated source and target positions.
- Renumber the session's exercise order transactionally and return the canonical order.
- Keep the top Active Workout summary card clean so it and the rest timer flow directly into Exercise 1, and place a compact `Reorder` trigger button alongside `+ Add Exercise` in a bottom 2-column exercise-action row (when 2+ exercises exist), above `Save to Program` and a 2-column `Cancel Workout` + `Finish Workout` completion row, that opens a compact `Reorder exercises` modal popup with 1-line sortable rows, step badges, set counts, and 44×44px 6-dot `@dnd-kit` drag handles (with touch, mouse, and keyboard `ArrowUp`/`ArrowDown` support).
- Apply an optimistic update and restore the prior order with an accessible error when persistence fails.
- Disable reordering while conflicting workout mutations are pending and hide reorder controls on completed workouts.

## Out of scope
- Reordering sets, changing the program day, or reordering completed workouts.
- Cross-workout templates and concurrent mutation hardening beyond the existing active-session guard.

## Acceptance criteria
- Owners can move any exercise to any valid position in their active workout.
- The order survives refresh and is reflected in the completed workout.
- Reordering does not change the source program.
- Unauthenticated, unauthorized, invalid, and completed-session requests are rejected consistently.
- The interaction works with touch and keyboard at 375px and exposes position changes to assistive technology.

## Verification
- Focused server route and workout-page tests.
- `npm run check`.
- Manual 375px touch and keyboard reorder, refresh, failure rollback, and completed read-only checks.

## Stop conditions
- Do not add set reordering or modify program-day order.

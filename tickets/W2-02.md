# W2-02: Always-Visible Previous-Workout References

State: ready

## Goal
Keep the latest completed performance for each exercise visible throughout an active workout, without requiring the add-set form to be open.

## Scope
- Reuse and verify the existing owner-scoped previous-workout payload.
- Define "previous" as the latest earlier completed session for the same exercise that contains at least one set.
- Move the compact previous-set line into each active exercise card's persistent content.
- Preserve warm-up, normal, and drop-chain order and identify the best normal set consistently with Progress.
- Show a concise empty state when no prior performance exists.
- Add server and client regression coverage for ordering, ownership, and presentation.

## Out of scope
- Weight-unit conversion, progress-chart work, and editable history.
- New analytics or comparisons across multiple earlier workouts.

## Acceptance criteria
- Every active exercise card shows either its latest previous workout or "No previous sets" while collapsed, expanded, and during set entry.
- References never use the current session, a later session, another user's data, or an unfinished workout.
- Warm-up and drop sets are labeled, drop chains remain understandable, and the best normal set is distinguishable.
- The reference wraps without horizontal scrolling at 375px.

## Verification
- Focused session API and workout-page tests.
- `npm run check`.
- Manual 375px checks with no history, mixed set kinds, long values, and collapsed/expanded cards.

## Stop conditions
- Do not add charts, multiple-workout history, or kg/lb conversion in this ticket.

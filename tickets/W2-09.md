# W2-09: Responsive SVG Progress Chart

State: proposed

## Goal
Add the mockup's responsive estimated-1RM line chart to Progress using the existing session trend data.

## Dependencies
- W2-08 establishes the display-unit contract used by chart labels and accessible descriptions.

## Scope
- Render a dependency-free SVG line chart from chronological per-session estimated 1RM points.
- Scale axes and labels for positive values, identical values, sparse data, and narrow viewports.
- Show compact date labels, unit-aware values, point markers, and an accessible text summary.
- Keep the existing session-history content as the detailed non-visual representation.
- Match the mockup's monochrome visual hierarchy and mobile-first card structure.

## Out of scope
- New progress metrics, date-range controls, zooming, tooltips requiring pointer hover, or a charting dependency.
- Server aggregate changes unless a small deterministic payload correction is required.

## Acceptance criteria
- Two or more sessions render a correctly ordered line and points without clipping.
- Zero or one session renders an intentional empty/single-point state without invalid geometry.
- Chart labels follow the user's kg/lb preference and the text alternative conveys the same trend.
- The chart is legible at 375px, responsive at desktop widths, and does not introduce horizontal page scrolling.

## Verification
- Focused chart geometry, unit-label, accessibility, and Progress-page tests.
- `npm run check`.
- Manual 375px and desktop checks for 0, 1, 2, flat, increasing, and decreasing data sets.

## Stop conditions
- Do not introduce a chart library or expand the progress API into new metrics.

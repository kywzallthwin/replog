# W1-09: Correct History And Progress Mobile Issues

**State:** proposed

## Goal
Fix confirmed mobile layout, empty-state, long-content, and accessibility issues in history and progress.

## Scope
- History list and completed-session navigation; progress statistics, trends, empty states, responsive summaries, and text overflow.

## Out of scope
- SVG chart, kg/lb preference, new calculations, or API aggregation.

## Acceptance criteria
- Screens work at 375px without horizontal scrolling.
- Empty, loading, error, and populated states remain distinguishable.
- Long names, values, and dates do not make controls unusable.
- Existing history and progress values remain unchanged.

## Verification
- Run focused client tests, lint, and typecheck.
- Manually check empty/populated screens and completed-session navigation at 375px.

## Stop conditions
- Stop if visual work requires changing calculations or adding deferred features.

Route /guide (planned - not yet built)

Guide

Estimated 1RM Personal Best

RepLog does not choose your personal best by raw heaviest weight alone.

Formula

estimated 1RM = weight x (1 + reps / 30)

100 kg x 12 reps

= 140 kg estimated 1RM

120 kg x 1 rep

= 120 kg estimated 1RM

So 100 kg x 12 can be treated as the stronger personal best.

Rules
  • Only finished workouts count.
  • Only Normal sets count.
  • Warm-up and Drop sets are excluded.
  • Raw heaviest set is shown separately.

Drop-set logging concept

Simple entry, accurate history

Add drop weight and reps beside the main set

Enter the normal set first, then add as many optional drop rows as needed. RepLog saves the complete chain together and keeps drops visually attached to the set that started it.

Design source: this mockup is the design spec RepLog gets built to match, not documentation of what's already shipped. It covers protected full-page routes, auth card shell, dashboard/profile actions, session add/swap/remove controls, in-app delete confirmation for both sets and exercises, history grouping, and estimated 1RM progress language. It also documents the History and Progress empty states new accounts see first, plus a forward-looking mock of the planned (not yet built) /guide route from TODO.md. Primary/brand color is near-black monochrome; category day badges keep their own accent colors.

Mobile-first rules: the built mobile layout is the primary target; desktop frames are an optional responsive stretch. The primary bottom navigation uses a refined floating dock with recognizable line icons, while the comparison frame above shows an edge-to-edge alternative with a short top active indicator. Both directions use consistent 44px tap targets and env(safe-area-inset-bottom) padding when fixed to the viewport. This mock keeps the docks sticky inside each phone frame and floats the active-workout time capsule above them. Weight and reps inputs open numeric keyboards (inputmode="decimal" / "numeric"). The rest timer stays visible while scrolling during an active workout.

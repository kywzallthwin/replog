### First Guide Entry: Estimated 1RM Personal Best

Explain that RepLog does not choose personal best by raw heaviest weight only.

Formula:

`estimated 1RM = weight x (1 + reps / 30)`

Examples:

- `100 kg x 12 reps = 140 kg estimated 1RM`
- `120 kg x 1 rep = 120 kg estimated 1RM`

So `100 kg x 12` can be treated as the stronger personal best.

Rules:

- Only finished workouts count.
- Only `NORMAL` sets count.
- `WARMUP` and `DROP` sets are excluded.
- Raw heaviest set is shown separately.
